# AGENTS.md

## Project

This is a beginner practice project for learning Codex.
The app is a simple Hit & Blow game written in Python.

## Environment

- Python 3.11
- Windows is the main target environment
- Start with a command-line version
- Later, add a Tkinter GUI version

## Rules

- Keep the code beginner-friendly and readable
- Prefer simple implementation over clever implementation
- Do not add unnecessary dependencies
- Do not make large changes unless requested
- Explain important changes briefly
- After changes, provide manual test steps

## Game rules

- The answer is a 4-digit number
- Digits must not be duplicated
- User input must be 4 digits
- User input must contain only numbers
- User input must not contain duplicate digits
- Hit means correct digit and correct position
- Blow means correct digit but wrong position

## Done means

- The app can be run locally
- Invalid input is handled without crashing
- The game can be restarted
- The README explains how to run it
